## Heating curve
The five stages have distinct placements relative to the plotted segments:
- Solid warms: above first rising segment.
- Melting: below first plateau.
- Liquid warms: above middle rising segment.
- Boiling: below second plateau.
- Gas warms: below final rising segment.
- Temperature constant: above each plateau.

A light background stroke around SVG text improves contrast and keeps the curve from visually running through glyphs.
